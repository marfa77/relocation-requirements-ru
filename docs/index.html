Требования ВНЖ и виз для релокации

Открытый датасет требований 13 программ ВНЖ и виз (Португалия D7/D8, Испания, Италия, Кипр, Германия, Сербия, Грузия, Таиланд): минимальный доход, сборы, сроки, путь к ПМЖ/гражданству — только из официальных источников. Пустое значение (—) = не удалось подтвердить на официальной странице; ничего не додумано. Проверено 2026-10-12. Скачать JSON · CSV · GitHub. Лицензия данных CC BY 4.0.
